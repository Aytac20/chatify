## 📖 About

Chatify is a full-stack real-time chat application built from scratch. Users can sign up, receive a welcome email, and instantly start chatting with online contacts. The app features typing indicators, online/offline presence, image uploads, and notification sounds — all wrapped in a clean and responsive UI.

---

## ✨ Features

- 🔐 **Custom JWT Authentication** — no third-party auth providers
- ⚡ **Real-time Messaging** via Socket.io
- 🟢 **Online/Offline Presence** indicators
- 🔔 **Notification & Typing Sounds** with toggle
- 📨 **Welcome Emails** on signup via Resend
- 🗂️ **Image Uploads** powered by Cloudinary
- 🚦 **API Rate-Limiting** powered by Arcjet
- 🎨 **Beautiful UI** with React, Tailwind CSS & DaisyUI
- 🧠 **Zustand** for lightweight state management

## 🚀 Getting Started
```bash
# Clone the repository
git clone https://github.com/your-username/chatify.git

# Install dependencies
cd chatify
npm install

# Set up environment variables
cp .env.example .env

# Run the app
npm run dev
```
